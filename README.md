## 🩺 About This Project
This is a **fully responsive Ayurvedic clinic website** built using HTML, CSS, and JavaScript. It is hosted for free on **GitHub Pages**.  
The website allows patients to:

- Learn about **5 major diseases** (Sciatica, Piles, Gout, Paralysis, Kidney Stone).
- Understand the **Ayurvedic treatments** and dietary suggestions for each disease.
- **Book an appointment** directly via **WhatsApp** without showing the doctor's phone number publicly.
